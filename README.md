## 1 核 1GB 跑得動什麼

1GB 記憶體在 2026 年是個很緊的數字。裝完 Ubuntu 22.04 或 Debian 12，系統本身吃掉 150–250MB，剩下的空間夠跑：

- Nginx 或 Caddy 反代 + 靜態站，記憶體佔用 100MB 以內
- 單站 WordPress 搭配 MariaDB 與 PHP-FPM，調低 PHP 進程數後勉強能跑，同時在線人數大概十幾人
- 自寫的 Go 或 Node.js 小 API，沒有框架包袱的話毫無壓力
- Prometheus 監控節點、Uptime Kuma、RSS 抓取、Telegram bot

跑不動的：WooCommerce 這類有購物車與結帳流程的電商、多站台 cPanel 環境、Elasticsearch、任何 JVM 應用、Docker 裡疊三層以上的服務。記憶體不足時 Linux 會啟動 OOM Killer，症狀是進程莫名消失、MySQL 無預警重啟，不會給你明確的錯誤訊息。

要 2GB 以上就得往上走，而這批特價方案的硬體是固定的，官網標示不可升級。真需要更多資源，得改看月付的 Pay As You Go 方案。

## 5Mbps 不限流量與 1TB 峰值：同一價格下的兩種限制

「不限流量」四個字容易誤導。5Mbps 的端口換算下來是 0.625MB/s，全速跑滿一個月約 1.6TB，這是你實際能拉到的上限；「不限」指的是不另外計費、不斷線，不是沒有天花板。

另一邊的 1TB 方案反過來：端口給你 10Mbps（1.25MB/s）或 20Mbps，但月流量只有 1TB。用 10Mbps 全速跑，大約 9 天就把一個月份的額度用完，剩下三週得限速或停著。

所以選擇規則很清楚：

- **流量平穩、持續低速**：監控、掛機、爬蟲、代理中轉、長時間連線的服務，選不限流量。5Mbps 對這類用途夠用，而且不怕某天流量爆掉。
- **有明顯峰值、總量可控**：网站有白天高峰、晚上離峰，或需要偶爾傳大檔，選 1TB 配 10Mbps 或 20Mbps。尖峰時段的速度體驗差一倍。

## 常見問題

**1 核 1GB 跑 WordPress 會不會當？**

單站、外掛裝得克制、日訪問量在幾百人以內，可以跑。同時在線十幾人以上，或裝了 WooCommerce、頁面建構器、多個快取外掛，記憶體會不夠，症狀是資料庫無預警重啟。要跑 WordPress 電商，直接看 2GB 以上的方案。

**5Mbps 端口能撐幾個人同時在線？**

看內容型態。純文字頁面一首頁 300KB，5Mbps 大約 2 秒載完，同時 2–3 人開啟還算順。圖片沒壓縮、或有人下載檔案，整條端口就滿了。這個端口適合低流量站與後端服務，不適合圖片站。

**年付 $24.99 之後會漲價嗎？**

官網標示特價套餐的庫存與線路可能調整，實際配置與價格以下單頁為準。續約價官網沒有另外標示，續約前先看帳單金額再決定要不要續。

**台灣節點一定是原生 IP 嗎？**

不能假設。有第三方測評測到該節點 IP 歸屬地不在台灣。要原生 IP 的用途（串流解鎖、本地帳號運營），下單前必須向客服確認，並在開通後自行檢測。

**沒有 Linux 基礎能用嗎？**

這是自主管理的 VPS，只給root權限的裸機環境，系統更新、防火牆、備份都要自己來。不會用 SSH 的話，先老實用虛擬主機，或選有代管服務的本地廠商。
